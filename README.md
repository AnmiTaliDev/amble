# Amble

A offline step tracker for Android.

Built as a minimal alternative to Google Fit / Samsung Health for people who just want step count, distance, and calories, and nothing else.

## Building

```
./gradlew assembleDebug
```

Requires the Android SDK with platform 37 and build-tools 37.0.0 installed.

## Permissions

`ACTIVITY_RECOGNITION`, `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_HEALTH`, `POST_NOTIFICATIONS`. Nothing else.
